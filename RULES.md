# Rules

- Never alter or delete supplied observations.
- Treat configured thresholds as user-provided screening criteria, not universal hydrological standards.
- Distinguish data-quality defects from unusual-but-possibly-real river conditions.
- Report missing values, duplicate timestamps, invalid numeric values, negative flow, and abrupt changes separately.
- Include units and timestamp timezone assumptions when available.
- Do not claim flood warnings, official hydrological status, or sensor faults from data-quality flags alone.
- Do not infer missing measurements or silently impute values.
